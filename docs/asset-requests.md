## 2. 공통 그림 규칙

| 항목 | 규칙 |
| --- | --- |
| 형식 | 손으로 정리한 SVG(벡터만). PNG·JPG를 SVG 안에 넣지 않는다. 파일 하나 30KB 이하 |
| 선 | 검정 `#000000`. 실제 그림 2px, 카드 그림 1.5px. `stroke-linecap="round"`, `stroke-linejoin="round"` |
| 면 | 아래 색표의 단색만. **그라데이션·그림자·질감·흐림 금지** |
| 글자 | 그림 안에 글자·숫자·눈금·자(ruler)·화살표 수치 **넣지 않음** |
| 사람 | 작고 단순한 모양, 표정은 중립. 우는 얼굴·위험에 빠진 모습·재난의 극적인 장면 금지 |
| 나라 표시 | 국기·지도 윤곽·나라 이름 넣지 않음 |
| 접근성 | `<svg>` 안 첫 줄에 `<title>`을 넣고, 내용은 json의 `imageAlt` 문장 그대로 |
| 배경 | 아래 묶음별 규칙대로 |

## 3. 묶음 A — ③ 4단계 실제 그림 (3장)

| 공통 | 값 |
| --- | --- |
| 위치 | `public/images/scenes/<id>.svg` |
| viewBox | `0 0 600 340` |
| 구도 | 디지털 수조와 같게 **왼쪽 바다, 오른쪽 땅**. 바닷물이 땅 쪽으로 들어와 무엇이 잠기는지 보이게 |
| 바탕 | 하늘 `#dceeff`를 꽉 채움 |
| 비우는 곳 | **왼쪽 위 160×56 영역**은 비워 둔다(앱이 "상상해 본 모습" 스티커를 얹음) |
| 물 | 단색 `#4da2ff` + 수면 선 `#1d6fd6` 3px. 잠긴 물체가 비쳐 보이게 물 면은 `fill-opacity="0.55"`로 물체 **앞에** 그린다 |

| id | 파일 | 그릴 것 | `<title>` (lab.json `imageAlt`) |
| --- | --- | --- | --- |
| `tuvalu` | `scenes/tuvalu.svg` | 낮고 평평한 섬, 야자수 2~3그루, 집 2~3채(주황 지붕), 섬을 가로지르는 길. 물이 길과 집 아래쪽까지 들어온 모습. 오른쪽 높은 쪽으로 걸어가는 작은 사람 1~2명 | 낮고 평평한 섬의 길과 집 아래쪽까지 바닷물이 들어온 모습을 상상해 그린 그림 |
| `maldives` | `scenes/maldives.svg` | 작은 섬 여러 개(3~4개)가 띄엄띄엄. 가장 큰 섬에 바닷가 마을(집 3채)과 나무 선착장. 선착장과 바닷가 집 일부가 잠김. 작은 배 1척 | 작은 섬 여러 개의 바닷가 마을과 선착장 일부가 잠긴 모습을 상상해 그린 그림 |
| `tidal-flat` | `scenes/tidal-flat.svg` | 넓은 갯벌(모래색 + 땅 점), 게 2~3마리, 조개, 갯벌 위를 나는 새 2마리. 물이 갯벌 대부분을 덮어 드러난 갯벌이 오른쪽 끝에만 조금 남은 모습. 사람 없음 | 넓은 갯벌 대부분이 바닷물에 덮여 게와 조개, 새가 쉴 곳이 줄어든 모습을 상상해 그린 그림 |

연결: `src/data/lab.json` → `real.scenes[].image`에 `"images/scenes/tuvalu.svg"`처럼 적는다(맨 앞 `/` 없이).

## 4. 묶음 B — ④ 영향 카드 그림 (11장)

| 공통 | 값 |
| --- | --- |
| 위치 | `public/images/cards/<카드 id>.svg` |
| viewBox | `0 0 300 200` (작은 카드 156×104, 크게 보기 480×200에 비율 유지로 들어감) |
| 바탕 | **투명** (카드가 영역 연한 색을 깔아 줌). 땅·하늘이 필요하면 아래 1/3 정도만 |
| 구성 | 대상 하나를 크게, 가운데. 작은 카드(156px 너비)에서도 알아볼 수 있게 굵고 단순하게 |
| 사건 표현 | 산불·태풍·홍수는 불길·파도를 크게 키우지 않고, **영향을 받는 대상**(숲, 집, 논밭)을 가운데에 |

| 카드 id | 영역 | 그릴 것 | `<title>` (cards.json `imageAlt`) |
| --- | --- | --- | --- |
| `heat-cold` | 생활 | 뜨거운 해(주황) 아래에서 손수건으로 땀을 닦는 사람(중립 표정) | 뜨거운 해 아래에서 땀을 닦는 사람 |
| `wildfire` | 생활 | 왼쪽에 숲 가장자리 마을(집 2채), 오른쪽 뒤 산에서 회색 연기가 피어오름. 불꽃은 작게 | 숲 가장자리에 있는 마을과 연기가 피어오르는 산 |
| `typhoon` | 생활 | 바람에 크게 휘어진 나무 1그루와 바닷가 집 1채, 바람 줄 3개 | 바람에 크게 휘어진 나무와 바닷가 집 |
| `flood` | 생활 | 물에 잠긴 길과 집 아랫부분, 집 앞에 우산 쓴 사람 1명(무릎 아래까지 물 아님, 높은 곳에 서 있음) | 물에 잠긴 길과 집 앞에 서 있는 우산 쓴 사람 |
| `food` | 생활 | 갈라진 밭(땅색 + 갈라짐 선), 시든 농작물 3포기, 앞쪽에 빈 그릇 1개 | 갈라진 밭과 시든 농작물 옆에 놓인 빈 그릇 |
| `tidal-flat` | 환경 | 갯벌 위의 게 1마리(크게)와 조개 2개, 위를 나는 새 1마리 | 갯벌 위의 게와 조개, 그 위를 나는 새 |
| `sea-forest` | 환경 | 바닷속 해조류(초록) 숲 사이를 헤엄치는 물고기 2마리. 아래 1/3 물 | 바닷속 해조류 사이를 헤엄치는 물고기 |
| `glacier` | 환경 | 산골짜기 사이에 남은 작은 빙하(흰색 + 하늘색 면, 검정 선) | 산골짜기에 남은 작은 빙하 |
| `bee` | 환경 | 꽃(분홍 대신 흰 꽃잎 + 노랑 가운데) 위에 앉은 꿀벌 1마리(노랑·검정 줄) | 꽃 위에 앉은 꿀벌 한 마리 |
| `mangrove` | 환경 | 물 위로 뿌리를 여러 갈래 내린 맹그로브 나무 1그루, 뿌리 사이 작은 물고기 1마리 | 물 위로 뿌리를 내린 맹그로브 나무와 그 사이의 작은 물고기 |
| `local-taebaek` | 우리 지역 | 단순한 지도 모양 종이(흰색, 접힌 선 2개) 위에 꽂힌 주황 지도 핀. **실제 지도 윤곽 아님** | 지도 위에 꽂힌 핀 |

연결: `src/data/cards.json` → `cards[].image`와 `localCard.image`에 `"images/cards/<id>.svg"`. (`localCard`에는 `image` 칸이 없으므로 새로 추가한다)
